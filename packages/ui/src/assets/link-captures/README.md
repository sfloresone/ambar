# Link captures (mock library)

Viewport captures of Example.org, Wikipedia's Amber article and W3.org, used by the mock library
(`@ambar/ui/lib/library-mock`) as the saved previews of three real, frameable links. `manifest.json` records
the source URLs, capture time and viewport. Each has a 320 px and a 640 px WebP at 16:10.

They stand in for the captures the server will take when a link is kept. Visual references only, not
archives; source content belongs to its owners. Replace with server captures once the API keeps links.
